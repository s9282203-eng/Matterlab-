Project objective

Use the same approved engine platform and controlled operating points to compare fuel energy input with measured brake output. Enter measured values in the calculator; results update immediately.

This is an offline data-entry and calculation tool. It does not connect to sensors or control engine hardware.

Fuel categories

  • Petrol — baseline
  • LPG / CNG — only with certified conversion
  • Hydrogen — specialist-approved system only
  • Diesel — separate compression-ignition reference engine, not a direct fuel swap

Quick start

  1. Open Test entry & calculator.
  2. Enter RPM, torque, fuel mass flow and fuel lower heating value (LHV).
  3. Brake power, fuel power and brake thermal efficiency appear as soon as the inputs are valid.
  4. Save the test point to add it to the comparison and export.
Carnot efficiency is an ideal temperature-limit benchmark, not the measured efficiency of a real engine. Use hot- and cold-reservoir temperatures that are physically justified.

Measured test inputs

Enter steady-state measurements. Blank fields are never silently treated as zero.

Equations used:
Pb = 2πNT / 60,000 (kW)
Pfuel = ṁ × LHV / 3.6 (kW, ṁ in kg/h)
ηbth = Pb / Pfuel × 100
ηCarnot = 1 − Tc/Th (kelvin)

Carnot is shown only when both temperatures are supplied and valid. Exhaust and coolant readings are never assumed to be reservoir temperatures.

Minimum measurement set

  • Engine speed and brake torque
  • Fuel mass flow and fuel LHV
  • Repeat measurements after stable operating conditions
  • Record ambient conditions, intake air, coolant and exhaust temperatures
  • Record emissions where suitable equipment is available

Experimental controls

  • Compare fuels at matched RPM and brake load.
  • Use consistent warm-up and stabilization criteria.
  • Repeat each operating point and report mean and variation.
  • Use the correct LHV and mass-flow basis for each fuel.
  • Do not compare a diesel reference engine as if it were the same engine.

Safety and compatibility

Fuel-system conversion, calibration and engine operation must be performed by qualified personnel using certified components, ventilation, leak detection, fire protection and applicable local regulations. Hydrogen, LPG and CNG require dedicated storage, regulators, injectors, shutoff systems and safety procedures. Diesel operation requires a compression-ignition engine; it is not a direct substitute in a normal petrol engine.

This prototype is an educational calculation aid only. It is not a design approval, operating procedure, safety certification or substitute for calibrated instruments.
